**Create Project Mode**

请调用skill： create-linear-project 完成五步协作循环（四格逼问→2-3 个方案权衡→挑战假设→锚定事实→收敛出计划），把模糊想法变成可审查的 Linear Project 草案。

详细要求信息：$ARGUMENTS

行为来源:linear-admin-core、project-planning、create-linear-project.

路由要求：
-先协作对话，再收敛计划。
-禁止在方案对比后直接进入选择或计划；必须先完成假设挑战与事实锚定。
